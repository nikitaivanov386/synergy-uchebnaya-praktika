## Описание

Репозиторий содержит практические задания, выполненные в рамках учебной ознакомительной практики.

В репозитории представлены программы на языке Python, разработанные в соответствии с индивидуальным заданием.

## Практические задания

### 1. Вычисление факториала

Файл: `factorial.py`

Программа запрашивает у пользователя положительное целое число и вычисляет его факториал с использованием стандартной библиотеки Python `math`.

Предусмотрены:

- проверка корректности ввода;
- обработка нечисловых данных;
- проверка положительности числа;
- повторный ввод при ошибке;
- вычисление факториала с использованием `math.factorial()`.

### 2. Игра «Угадай число»

Файл: `guess_number.py`

Консольная игра, в которой программа случайным образом загадывает число от 1 до 100, а пользователь должен его угадать.

Предусмотрены:

- генерация случайного числа;
- ввод предположения пользователя;
- проверка корректности ввода;
- подсказки «Слишком большое число» и «Слишком маленькое число»;
- ограничение количества попыток;
- сообщение о победе;
- возможность начать новую игру.
